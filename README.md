## About the website

The Graffiti Kings Wiki documents the street-art roots and fictional world of **Graffiti Kings**, **GKniftyHEADS**, **GraffPUNKS**, and the wider **Crypto Moonboys** universe. It connects graffiti, hip-hop and street culture with Web3 storytelling, characters, factions, collectibles and speculative future history.

The site's lore features **Block Topia**, **the Grid**, **40 factions**, the **Hard Fork** conflicts and a future setting in **3008**. The archive distinguishes the real-world cultural foundation from its fictional world-building.

## Repository structure

- `index.html`, `about.html`, `history.html` — main site pages
- `characters/` — character entries and index
- `factions/` — faction entries and index
- `pages/` — additional wiki topics
- `css/` — styling
- `js/` — client-side functionality
- `images/` — artwork and visual assets
- `_article-template.html` — template for wiki articles

This is an HTML/CSS/JavaScript website. It does not require a separate frontend build step to view its pages locally.

## View locally

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/graffiti-kings/graffiti-kings.git
cd graffiti-kings
```

For a local HTTP server, if Python is installed:

```bash
python -m http.server 8000
```

Then open http://localhost:8000/.

## Lore and source notes

The existing wiki pages describe the **W81 archive** as their working source base. Treat the site as an evolving archive: distinguish real-world history from fictional lore, and review source/canon claims before publishing changes. Related project and writing sources linked from the wiki include:

- [Crypto Moonboys](https://cryptomoonboys.com/)

## Contributions

When proposing updates, keep navigation links valid, use the existing article template where appropriate, and clearly identify whether material is documented history, sourced lore, or new fiction.
