> The site is hosted on GitHub Pages using the verified custom domain `graffitikings.com`. Domain DNS is managed through GoDaddy.

## About the website

The Graffiti Kings Wiki documents the street-art roots and fictional world of **Graffiti Kings**, **GKniftyHEADS**, **GraffPUNKS**, and the wider **Crypto Moonboys** universe. It connects graffiti, hip-hop and street culture with Web3 storytelling, characters, factions, collectibles and speculative future history.

The site's lore features **Block Topia**, **the Grid**, **40 factions**, the **Hard Fork** conflicts and a future setting in **3008**. The archive distinguishes the real-world cultural foundation from its fictional world-building.

## Repository structure

- `index.html`, `about.html`, `history.html` — main site pages
- `characters/` — character entries and index
- `factions/` — faction entries and index
- `pages/` — additional wiki topics
- `css/` — styling
- `js/` — client-side functionality
- `images/` — artwork and visual assets
- `_article-template.html` — template for wiki articles

This is an HTML/CSS/JavaScript website. It does not require a separate frontend build step to view its pages locally.

## View locally

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/graffiti-kings/graffiti-kings.git
cd graffiti-kings
```

For a local HTTP server, if Python is installed:

```bash
python -m http.server 8000
```

Then open http://localhost:8000/.

## Publication

This repository's default branch is `main`. To publish as a GitHub Pages project site, enable GitHub Pages in the repository settings and select the appropriate publishing source. The public website URL is https://graffitikings.com/. Configure this under **Settings → Pages → Custom domain**.

## Real-world evidence and social-link policy

The SER / Graffiti Kings research pages distinguish third-party reporting, first-person interviews, historical auction catalogues, project-authored publicity and publicly declared account handles. External links are a curated reference trail; they **do not** imply an incoming backlink, current account control, endorsement or a currently operating legacy app. Real-world history must remain separate from fictional W81/Year 3008 lore. Do not copy copyrighted articles or image assets into this repository.

The expanded history is at [SER documented history](pages/darren-cullen-ser-history.html); original source links and account provenance are in the [web network directory](pages/graffiti-kings-web-network.html).
