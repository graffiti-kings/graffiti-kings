Overview

Rune Tag is a W81 character built around the oldest function of graffiti: the mark that proves someone was there. In the Graffiti Kings universe, a tag is not just a name. It is identity, location, memory, warning, ownership, rhythm, and code. Rune Tag takes that logic and pushes it into glyph form.

The character bridges ancient symbol language and digital chain memory. A rune can be read as magic, but in this wiki it should be treated as compressed information. A tag can be read as vandalism by outsiders, but inside the archive it is proof of presence. Rune Tag stands where those two systems overlap.

Glyph Logic

Rune Tag's marks are not decoration. Each glyph should imply stored meaning: faction route, hidden archive sector, lost holder address, Chain Scribe warning, SAM recovery point, or a fragment of W81 memory that cannot be written in plain language without becoming unstable.

The character should be used when normal text is insufficient. Rune Tag does not explain everything. They leave marks that pull other characters into interpretation.

Wall and Chain Function

On the wall, Rune Tag operates through symbols. On the chain, the same logic becomes metadata, trait language, hash fragments, and scroll marks. This makes the character useful for NFT pages, faction pages, relic pages, and mysteries where the archive is hiding information in plain sight.

Rune Tag should not replace Chain Scribes or prophets. Their function is more physical and more visual: the coded mark that appears before the explanation does.

Canon Boundaries

Future Rune Tag lore must remain tied to glyphs, tags, encoded marks, hidden memory, and street-to-chain symbol systems. Do not turn the character into unrelated fantasy magic. Keep every expansion connected to the Graffiti Kings wall language and W81 archive logic.
